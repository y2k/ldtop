# Инструкции для агентов

- Разрабатываем обёртку над macOS `launchd` и `launchctl`.
- Разработка ведётся через OpenSpec.
- При разработке спеки OpenSpec добавляй в список задач пункт о запуске ревью реализации и исправлении всех очевидных или важных находок до завершения работы.
- По умолчанию работай в ветке `main`, в основном worktree, без субагентов, если пользователь явно не указал другое.
- В начале каждой сессии загружай скилл `ponytail` и следуй его инструкциям.
