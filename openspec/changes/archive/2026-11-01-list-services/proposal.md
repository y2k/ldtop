# Proposal

## Why

Сейчас `ldtop` выводит только `Hello, world!`. Первый полезный сценарий — посмотреть зарегистрированные службы текущего пользователя одной командой, без изучения интерфейса `launchctl`.

## What Changes

- Добавить `ldtop ls`: разовый список из `launchctl list`, включая службы без запущенного процесса.
- По умолчанию скрывать службы, чьи Label начинаются с `com.apple.` (с учётом регистра), чтобы уменьшить шум. Флаг отключения фильтра не добавлять.
- Выводить таблицу `Label`, `PID`, `Last exit`, отсортированную по `Label`; отсутствующий PID обозначать `—`.
- Передавать ошибки в stderr и завершаться с ненулевым кодом.
- Обновить справку CLI. Интерактивный режим, настраиваемые фильтры, системные домены и поиск незагруженных `.plist` не входят в изменение.

## Capabilities

### New Capabilities
- `service-listing`: просмотр зарегистрированных служб в текущем пользовательском контексте `launchctl`.

### Modified Capabilities

Нет.

## Impact

Затронуты `bin/main.ml`, настройки Dune в `bin/`, `lib/`, `test/` и новые небольшие модули получения, разбора и отображения списка. Используются OCaml, стандартная библиотека Unix и системный `/bin/launchctl`, без сторонних зависимостей. Службы не изменяются.
