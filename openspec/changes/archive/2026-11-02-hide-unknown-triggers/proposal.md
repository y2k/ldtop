# Proposal

## Why

Пользователь хочет всегда скрывать службы, для которых `Triggers=unknown`, чтобы они не занимали место в таблице.

## What Changes

- **BREAKING**: `ldtop ls` автоматически исключает строки с полностью неизвестными триггерами.
- Значения `plist:none-known` и частичные сведения вроде `plist:load,unknown` остаются видимыми.
- Фильтр не имеет флага отключения; диагностика ошибок сохраняется.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `service-listing`: постоянная фильтрация строк по доступности сведений о триггерах.

## Impact

`lib/service_listing.ml` (вывод после сбора подробностей), тесты таблицы и CLI, справка `bin/main.ml` и `README.md`. Новые зависимости не нужны. Ранее спецификация требовала сохранять строки при недоступных подробностях; теперь это правило подчиняется фильтру триггеров.
